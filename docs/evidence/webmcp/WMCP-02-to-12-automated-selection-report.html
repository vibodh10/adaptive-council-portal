To report a leaking ceiling, I’ll need these details:

**Required**
- **Address** of the council property where the leak is
- **Repair type (category):** usually **roof_or_ceiling** (or **plumbing** if you know it’s from a pipe/flat above)
- **Description of the problem:** what you can see (where the leak is, how much water, stains/bubbling plaster, dripping, any collapse)
- **When it started:** the date you first noticed it (**YYYY-MM-DD**, not a future date)
- **Is it getting worse?** (yes/no)
- **Is there immediate danger right now?** (yes/no) — e.g., ceiling might collapse, water near electrics, major flooding

**Optional (helps repairs attend)**
- **Access notes:** entry instructions, best times, door code, pets, vulnerable residents, etc.
- **Additional notes:** anything else useful (e.g., only happens when raining, leak from bathroom above, photos mentioned if the site allows)

If you tell me those, I can fill in the repair report with you.

get_housing_repair_draft
Use this when the person asks what repair information is currently entered, which required answers are missing, or whether the report is ready for review. It reads the same visible draft without changing, reviewing or submitting it.
update_housing_repair_draft
Use this when the person provides or corrects housing repair information and wants it entered into the report. It updates only the supplied fields in the same visible draft the person sees; it does not open review, submit the repair or create a reference.
open_housing_repair_review
Use this when the person wants to see, check or review their complete housing repair report before anything is sent. It validates the current shared draft and opens the visible review screen only when the report is complete; it never submits or creates a reference.
